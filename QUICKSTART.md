# 🚀 Быстрый старт

Полностью готовое веб-приложение **Test-cases Generator** установлено и готово к запуску!

## ⚡ За 2 минуты до работы

### Шаг 1: Откройте терминал в папке проекта
Перейдите в папку: `c:\Users\Admin\Downloads\VibeCode\tests_from_screen\tests_from_screenshot`

### Шаг 2: Создайте и активируйте виртуальное окружение

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3: Установите зависимости
```bash
pip install -r requirements.txt
```

### Шаг 4: Настройте API ключ

Откройте файл `.env` и замените:
```
MENTORPIECE_API_KEY=your_api_key_here
```
на ваш реальный API ключ от MentorPiece

Пример:
```
MENTORPIECE_API_KEY=sk-1234567890abcdefghijklmnop
```

### Шаг 5: Запустите приложение
```bash
python app.py
```

Вы увидите:
```
✓ API ключ загружен
🚀 Запускаем Flask приложение на http://localhost:5000
```

## 🌐 Откройте приложение

1. Откройте браузер
2. Перейдите на: **http://localhost:5000**
3. Опишите поля веб-формы в текстовом поле
4. Нажмите кнопку генерации тест-кейсов и дождитесь результата

## 🛠️ Если что-то не работает

1. **API ключ не найден**
   - Проверьте, что в `.env` правильно указан `MENTORPIECE_API_KEY`

2. **Зависимости не установлены**
   - Запустите: `pip install -r requirements.txt`

3. **Порт 5000 занят**
   - Измените в `app.py`: `app.run(debug=True, host='0.0.0.0', port=5001)`

4. **Python не найден**
   - Убедитесь, что Python 3.10+ установлен: `python --version`
