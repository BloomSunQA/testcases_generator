# Test-cases Generator 🚀

Веб-приложение для автоматической генерации и оценки тест-кейсов на основе описания веб-форм с использованием AI/LLM.

## 📋 Описание

Приложение позволяет:
- 📝 Описывать поля веб-форм в текстовом виде
- 🤖 Автоматически генерировать полный набор тест-кейсов (позитивные и негативные сценарии)
- ⭐ Оценивать качество сгенерированных тестов по 10-балльной шкале
- 🛡️ Безопасно обрабатывать ошибки и таймауты

## 🏗️ Технический стек

- **Python 3.10+**
- **Flask** - веб-фреймворк
- **Requests** - HTTP клиент для API запросов
- **python-dotenv** - управление переменными окружения
- **Werkzeug** - WSGI утилиты
- **Bootstrap 5** - фронтенд фреймворк

## 📦 Установка и запуск

### Windows

#### 1. Клонируйте или загрузите проект
```bash
# Если используете git
git clone <repository-url>
cd testcases_generator
```

#### 2. Создайте виртуальное окружение
```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
venv\Scripts\activate
```

#### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

#### 4. Настройте переменные окружения
```bash
# Скопируйте файл примера
copy .env.example .env

# Отредактируйте .env файл и добавьте ваш API ключ
# Откройте .env в текстовом редакторе и замените:
# MENTORPIECE_API_KEY=your_api_key_here
# на ваш реальный API ключ
```

Содержимое нового `.env`:
```env
MENTORPIECE_API_KEY=ваш_api_ключ_здесь
FLASK_ENV=development
FLASK_DEBUG=True
```

#### 5. Запустите приложение
```bash
python app.py
```

Приложение запустится на `http://localhost:5000`

## 🎯 Как пользоваться приложением

### Основной процесс

1. **Откройте приложение**
   - Перейдите на `http://localhost:5000` в браузер

2. **Опишите форму**
   - В текстовом поле опишите поля формы, на которую необходимо сгенерировать тест-кейсы, их типы и ограничения
   - Пример: "Email поле (обязательное, валидация email), Пароль (минимум 8 символов), Чекбокс 'Запомнить меня'"

3. **Сгенерируйте тест-кейсы**
   - Нажмите кнопку "🎯 Сгенерировать тест-кейсы (GPT-5.1)"
   - Приложение отправит описание на анализ
   - **Первый этап**: Модель GPT-5.1 генерирует полный набор тест-кейсов
   - Это может занять 30-120 секунд

4. **Оцените качество (опционально)**
   - Нажмите кнопку "⭐ Оценить с помощью LLM-as-a-judge"
   - **Второй этап**: Модель Claude анализирует и оценивает тест-кейсы   
   - Если Claude возвращает ошибку, применяется fallback на `google/gemma-3-27b-it`   
   - Модель проставляет оценку по 10-балльной шкале

5. **Создайте новые тест-кейсы**
   - Нажмите "🔄 Создать новые тест-кейсы" для нового описания формы

## ⚙️ API Интеграция

### Используемые API

#### 1. Генерация тест-кейсов
- **Модель**: `gpt-5.1-2025-11-13` (текстовая генерация)
- **Входные данные**: Текстовое описание формы
- **Задача**: Генерация полного набора тест-кейсов на основе описания

#### 2. Оценка качества
- **Модель**: `claude-sonnet-4-5-20250929` (текстовая оценка)
- **Fallback**: `google/gemma-3-27b-it`, если Claude возвращает ошибку
- **Входные данные**: Сгенерированные тест-кейсы
- **Задача**: Анализ качества тест-кейсов по критериям

### Параметры API

```
Endpoint: https://api.mentorpiece.org/v1/process-ai-request

Headers:
  - Authorization: Bearer {MENTORPIECE_API_KEY}
  - Content-Type: application/json

Body:
{
  "model_name": "модель",
  "prompt": "текст промпта"
}

Response:
{
  "response": "текст ответа"
}

Timeout: 120 секунд
```

## 🛡️ Обработка ошибок

Приложение корректно обрабатывает следующие ошибки:

| Ошибка | Причина | Решение |
|--------|---------|--------|
| API ключ не найден | `MENTORPIECE_API_KEY` не установлен | Добавьте ключ в `.env` файл |
| Неверный API ключ | Ключ неверный или просроченный | Проверьте ключ в `.env` |
| Таймаут API | Запрос занял более 120 сек | Попробуйте снова позже |
| Ошибка подключения | Нет интернета | Проверьте подключение |
| Пустое описание | Пользователь не ввел описание формы | Введите описание формы и повторите запрос |
| Неверный ответ API | API вернул неожиданный формат | Проверьте лог и попробуйте снова |
| Лимит запросов | API лимит превышен | Подождите и попробуйте позже |

## 🔧 Развертывание в продакшене

### Используя Gunicorn (Linux/macOS):

```bash

pip install gunicorn

# Запустите приложение
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### Используя waitress (Windows):

```bash
# Установите waitress
pip install waitress

# Запустите приложение

```

### Docker

```dockerfile
FROM python:3.10-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "app:app"]
```

- **Переиспользование HTTP соединений** - используется `requests.Session()`
